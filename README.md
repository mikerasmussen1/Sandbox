# Sandbox

Sunstone Siege lives in `sunstone-siege/`. It is a standalone jungle tower defense demo: Vite, TypeScript, PixiJS, and Howler. There is no account and nothing to buy.

Play: https://mikerasmussen1.github.io/Sandbox/

Jade is a demo token spent inside a valley. It stays in this browser and has no cash value. Stars and settings are stored in `localStorage`.

Auric Dynamo lives in `auric-dynamo/`. It is a static demo-play preview. Credits stay in this browser. There is no wallet and no real money.

Play: https://mikerasmussen1.github.io/Sandbox/auric-dynamo/

Lantern Tide lives in `lantern-tide/`. It is a static demo-play preview. The balance is labeled Demo and stays in this browser. There is no wallet and no real money.

Play: https://mikerasmussen1.github.io/Sandbox/lantern-tide/

Wyvern Wilds lives in `wyvern-wilds/`. It is a static demo-play preview. Shots spend demo credits that stay in this browser. There is no wallet and no real money.
