# Thunderscale Depths

The built table. `index.html` loads `js/game.js` and `css/game.css`. Art, audio and fonts live under `assets/`. `game-data.json` is generated by `pnpm -C apps/api game-math-sheets` and is the help screen's source for the disclosed return.

One shot that hits is one round, settled by the server. A miss is not posted. The balance shown is the server balance minus reserved stakes.

The lobby tile is `art/tile.jpg` (900 by 1200, no words), registered in `apps/player/lib/key-art.ts`. Sprite sheets are `assets/sprites/<id>.json` and `<id>.webp`, listed in `assets/sprites/index.json`. See the source README in `apps/player/games/thunderscale-depths` for the id list, the cannons and the boss segments.
